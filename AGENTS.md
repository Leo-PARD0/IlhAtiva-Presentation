# Project context

This is a local, offline-first presentation app built with React, Vite, and TanStack Router. Source files use JavaScript and JSX.

## Structure

- `src/routes/` contains the home, stage, controller, and prototype routes.
- `src/lib/presentationStore.js` owns the shared presentation state. Preserve its local `BroadcastChannel` and `localStorage` synchronization.
- `src/components/stage/`, `src/components/controller/`, `src/components/prototype/`, `src/components/shared/`, and `src/utils/` contain presentation behavior and visuals; preserve them unless the task specifically asks for changes.
- `src/routeTree.gen.ts` is generated by the TanStack Router Vite plugin; do not edit it manually.

## Local workflow

- `npm run dev` starts the local Vite server.
- `npm run lint` checks the JavaScript and JSX.
- `npm run build` creates the static site in `dist/`.
- The app has no backend, account/session requirement, or runtime dependency on external services.
